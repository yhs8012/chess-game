# 기물 3D 모델

`chess-set.glb`를 이 폴더에 넣으면 임시 Lathe 기물 대신 그 모델을 씁니다.

- 6종 기물이 **이름으로 구분되는 노드**로 들어 있어야 합니다: `pawn`, `rook`, `knight`, `bishop`, `queen`, `king` (대소문자 무관, 이름에 포함되면 인식)
- 크기·원점은 상관없습니다. 킹 높이를 기준으로 자동 정렬·스케일됩니다.
- 재질은 코드에서 회양목·흑단 재질로 덮어씌웁니다.
- 권장: Draco 압축, 기물당 폴리곤 5k 이하, 총 5MB 이하
- 라이선스는 CC0 우선. CC-BY면 `CREDITS.md`에 모델명·작가·링크·라이선스를 적어야 합니다.

파일이 없거나 6종을 찾지 못하면 자동으로 Lathe 기물로 돌아갑니다.
